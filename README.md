# Avaliação Fiscal — Releases

Repositório público de distribuição do Avaliação Fiscal.

Este repositório contém somente metadados e pacotes binários de atualização assinados.
O código-fonte permanece no repositório privado `Sontakayama/avaliacao-fiscal`.

## Segurança
- Pacotes usam o formato `AF-UPDATE-1`.
- Toda atualização precisa ter assinatura RSA/SHA-256 válida.
- A chave privada de atualização nunca é armazenada neste repositório.
- O cliente valida a assinatura antes de aplicar qualquer arquivo.
